# Hands-on Project: Generative AI for Data Insights 
Use efficient prompts on a Generative AI platform to create a Python script for generating insights on a data set available in a CSV file.
Source: [Coursera] (https://www.coursera.org/learn/generative-ai-elevate-your-data-science-career/ungradedLti/sF3aF/hands-on-lab-generative-ai-for-data-insights)

## Objectives

Create prompts to generate Python code that can:

- Generate a statistical description of all features in the dataset.
- Generate regression and box plots for different attributes to compare their distributions against a target attribute.
- Evaluate correlation values, Pearson coefficients, and p-values for different parameters in the dataset with the target parameter.
- Create pivot tables for groups of parameters and visualize them using `pcolor` plots.
